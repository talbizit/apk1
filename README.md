# Clock App

A simple Android clock app that displays the current time and allows you to change the background color.

## Features

- Real-time clock display (HH:mm:ss format)
- Background color picker with 6 color options:
  - Red
  - Green
  - Blue
  - Yellow
  - Purple
  - White

## Installation

Download the latest APK from the [Releases](../../releases) page and install it on your Android device.

## Building from Source

1. Clone this repository
2. Open in Android Studio or use the command line:
```bash
./gradlew assembleRelease
```

The APK will be generated in `app/build/outputs/apk/release/`

## Requirements

- Android 7.0 (API 24) or higher
